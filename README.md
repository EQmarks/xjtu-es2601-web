# 储能2601 团支部 · 最佳团日成果展示网站

> 第四十一届"最佳团日"成果展示站
> 主题：**《储百卅之光，能万里新程》** ｜ 报送全称：《赓续红色薪火，储启百卅新程》
> 主办：西安交通大学钱学森书院 储能2601 团支部 ｜ 指导：共青团西安交通大学委员会

---

## 一、这是什么

一个**纯静态**成果展示网站，不需要服务器、不需要数据库。

**核心亮点**：`index.html` 里的 **红色足迹 2.5D 等距地图**（纯 SVG 手绘，无依赖）。

**后期规划**：本站结构预留了扩展位，可平滑改造成**储能2601 班级官网**（详见下节"换肤"）。

---

## 二、技术栈

| 项 | 选择 | 原因 |
|---|---|---|
| 框架 | **无**（原生 HTML/CSS/JS） | 零依赖、双击即开、部署零成本 |
| 地图 | **原生 SVG + CSS 动画** | 不引入 Three.js/ECharts，体积小、加载快 |
| 样式 | **CSS 变量主题** | 换肤只改 `:root` |
| 构建 | **无** | 改完直接刷新 |

## 五、换肤（红色 → 蓝色）

全站颜色**只引用 CSS 变量**。改 `index.html` 顶部 `:root` 即可整体换肤：

```css
/* 当前：红色（团日主题） */
:root{
  --brand:#C8102E;        /* 主色·中国红 */
  --brand-deep:#8B0A1E;   /* 深红 */
  --brand-light:#E63A50;
  --brand-tint:#FFF1F3;
  --accent:#D4AF37;       /* 辅色·金 */
  --page-bg:#FAF7F5;      /* 暖白底 */
  ...
}

/* 蓝色主题（班级官网）—— 取消注释即切换
:root{
  --brand:#1A4D8F; --brand-deep:#0E2F5C; --brand-light:#2E6DB4;
  --brand-tint:#EFF5FC; --accent:#C9A227;
  --ch1:#1A4D8F; --ch2:#0E2F5C; --ch3:#2E6DB4; --ch4:#C9A227;
  --page-bg:#F5F7FA; --line:#E0E6ED;
}
*/
```

## 七、部署到 GitHub Pages

```bash
# 0. 配置身份（只需一次，换成你自己的）
git config user.name  "你的名字"
git config user.email "你的邮箱"

# 1. 在 GitHub 网页新建空仓库，复制其 URL，然后：
git remote add origin https://github.com/<你的用户名>/<仓库名>.git

# 2. 推送
git push -u origin main
```

**然后**：仓库页 → `Settings` → `Pages` → Source 选 `Deploy from a branch` → 分支选 `main`、目录选 `/ (root)` → `Save`

等 1-2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

> 💡 也可用 **Cloudflare Pages**：支持**拖拽文件夹上传**（不用 git），`*.pages.dev` 国内可达性通常更好。
> 建议**两边都部署**：Cloudflare 当主链接，GitHub Pages 当备用。
